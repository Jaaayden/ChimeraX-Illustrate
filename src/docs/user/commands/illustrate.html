illustrate command

illustrate opens the Illustrate tool.

illustrate capture captures atoms represented by visible atoms, cartoons, or molecular surfaces together with the current view.

illustrate save filename [transparent true|false] exports a PNG.

illustrate reset removes the captured snapshot.

The tool window's 恢复默认参数 button resets display parameters without removing the snapshot.

The 一键链配色 button applies the built-in chain palette to all open atomic models; capture again afterward to update the snapshot.
