illustrate command

illustrate opens the Illustrate tool.

illustrate capture [preferAtomColors true|false] captures atoms represented by visible atoms, cartoons, or molecular surfaces together with the current view. With preferAtomColors true, atoms shown only as cartoon or surface keep their own atom colors.

illustrate save filename [transparent true|false] [width w] [height h] [preferAtomColors true|false] exports a PNG (2–16000 pixels per side, default 1200; images above about 36 megapixels need several GB of memory and may take minutes). The command is synchronous: the file is complete when it returns. If the tool window holds a captured snapshot, that snapshot is exported with its tuned parameters; otherwise the current scene is captured directly. This form also works in ChimeraX --nogui.

illustrate reset removes the captured snapshot. show, capture, and reset need the graphical interface.

The Reset Defaults button (Advanced settings, General tab) resets display parameters without removing the snapshot.

The Apply Colors button applies the selected color preset to all open atomic models; capture again afterward to update the snapshot. Unless Adjust scene when applying colors (Advanced settings, General tab) is cleared, it also hides hydrogens and sets a white background, soft lighting, and silhouettes.
