illustrate command

illustrate opens the Illustrate tool.

illustrate capture [preferAtomColors true|false] captures atoms represented by visible atoms, cartoons, or molecular surfaces together with the current view. With preferAtomColors true, atoms shown only as cartoon or surface keep their own atom colors.

illustrate save filename [transparent true|false] [width w] [height h] [preferAtomColors true|false] exports a PNG (2–8000 pixels per side, default 1200). The command is synchronous: the file is complete when it returns. If the tool window holds a captured snapshot, that snapshot is exported with its tuned parameters; otherwise the current scene is captured directly. This form also works in ChimeraX --nogui.

illustrate reset removes the captured snapshot. show, capture, and reset need the graphical interface.

The tool window's Reset Defaults button resets display parameters without removing the snapshot.

The Apply Colors button applies the selected color preset to all open atomic models; capture again afterward to update the snapshot. Unless Also adjust scene is cleared, it also hides hydrogens and sets a white background, soft lighting, and silhouettes.
