Illustrate

The Illustrate tool captures atoms represented by visible atoms, cartoon residues, or molecular-surface patches together with the current camera view, then renders a non-photorealistic molecular illustration made from atomic spheres. Hidden models remain excluded. Capture a new scene after changing the ChimeraX camera. Parameter changes after capture update the preview after a short debounce.

The color-preset menu provides Classic Chains, Cool/Warm Complex, Nucleic Base Contrast, MotM Spectrum, and Monochrome Blues. Presets color open atomic models by chain and apply element-relative shades. Unless Adjust scene when applying colors (Advanced settings, General tab) is cleared, they also hide hydrogens and set a white background, soft lighting, and ChimeraX silhouettes. Nucleic Base Contrast assigns a separate soft color to every protein or nucleic-acid chain, keeps that color on each nucleic sugar-phosphate backbone, and colors the nucleobases pale warm gray to reveal the paired interior. This atom-level contrast is retained when atom, cartoon, or surface representations are captured, because the preset switches on Atom colors (also available on its own for any scene). Click Capture Current Scene after coloring to refresh the Illustrate snapshot.

The default contour level is 4, matching the reference Illustrate input; levels 1–3 remain available for sharper outlines. The default shadow floor and residue-number difference also follow that reference style. The main panel holds only the basics: Capture Current Scene, Export PNG, the export size, the color preset, and the Transparent, Lock scene and Atom colors options. All style parameters live in the collapsible Advanced settings tabs (Contour, Borders, Shading, General), so the window keeps the same size when you switch tabs or language. The General tab's Reset Defaults restores the export size, style values, shadow, transparency, and contour level without clearing the captured scene. The interface starts in English; use the 中文 button to switch between English and Chinese.

The controls are on the left and a large square preview is on the right; in a narrow or tall window the blocks stack, and a short window scrolls instead of squeezing the preview. The Help button and control tooltips describe each parameter, practical ranges, and how larger or smaller values affect the image. The Export size menu offers square presets (300, 600, 1200, 2400, 4800 and 8000 pixels); choose Custom to enter any width and height from 2 to 16000 pixels. A 16000 × 16000 export needs about 6–8 GB of memory and several minutes, and a notice is shown before very large exports start. The original Fortran program used a fixed 3000-pixel frame buffer; this bundle uses dynamic NumPy buffers and scales the pixel-based contour, boundary, and shadow neighborhoods from a 1200-pixel reference so changing the export size does not substantially change the visual style. Images narrower than 1200 pixels are rendered at 1200 pixels and shrunk by area averaging, so small exports (and the preview) keep the 1200-pixel outline weight. Images above 2048 pixels are processed in row tiles to avoid constructing several full-frame temporary arrays at once; larger images still require more time and memory. Raster and shadow results are cached, transparent regions are excluded from post-processing, sphere rasterization is vectorized, and large soft-shadow passes use multiple CPU cores. PNG compositing, compression, and writing are streamed in the background so the ChimeraX interface remains responsive and high-resolution exports avoid a second full-frame RGBA allocation.

The output uses atomic spheres even when the source representation is cartoon or molecular surface; the original cartoon or surface mesh is not rasterized. The output uses an orthographic projection to match the original Illustrate renderer; perspective cameras are accepted but may show a scale difference.
