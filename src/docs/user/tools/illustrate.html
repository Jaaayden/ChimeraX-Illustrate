Illustrate

The Illustrate tool captures atoms represented by visible atoms, cartoon residues, or molecular-surface patches together with the current camera view, then renders a non-photorealistic molecular illustration made from atomic spheres. Hidden models remain excluded. Capture a new scene after changing the ChimeraX camera. Parameter changes after capture update the preview after a short debounce.

The 一键链配色 button colors all open atomic models by chain, applies chain-relative element shades, hides hydrogens, and sets a white background, soft lighting, and ChimeraX silhouettes. Click 捕获当前场景 after coloring to refresh the Illustrate snapshot.

The default contour level is 4, matching the reference Illustrate input; levels 1–3 remain available for sharper outlines. The default shadow floor and residue-number difference also follow that reference style. The output-size controls are arranged in one row, and 恢复默认参数 restores preview size, export size, style values, shadow, transparency, and contour level without clearing the captured scene.

The preview is capped at 320 pixels high and the style controls are in a bounded scroll area, so opening the tool does not force the ChimeraX window off-screen. The 参数说明 button and control tooltips describe each parameter, practical ranges, and how larger or smaller values affect the image. Export width and height accept 2–8000 pixels. The original Fortran program used a fixed 3000-pixel frame buffer; this bundle uses dynamic NumPy buffers and scales the pixel-based contour, boundary, and shadow neighborhoods from a 1200-pixel reference so changing the export size does not substantially change the visual style. Exports above 4096 pixels are processed in row tiles to avoid constructing several full-frame temporary arrays at once; larger images still require more time and memory.

The output uses atomic spheres even when the source representation is cartoon or molecular surface; the original cartoon or surface mesh is not rasterized. The output uses an orthographic projection to match the original Illustrate renderer; perspective cameras are accepted but may show a scale difference.
