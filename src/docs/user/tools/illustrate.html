Illustrate

The Illustrate tool captures atoms represented by visible atoms, cartoon residues, or molecular-surface patches together with the current camera view, then renders a non-photorealistic molecular illustration made from atomic spheres. Hidden models remain excluded. Capture a new scene after changing the ChimeraX camera. Parameter changes after capture update the preview after a short debounce.

The color-preset menu provides Classic Chains, Cool/Warm Complex, Protein Blue/Nucleic Orange, MotM Spectrum, and Monochrome Blues. Presets color open atomic models by chain or molecule type, apply element-relative shades, hide hydrogens, and set a white background, soft lighting, and ChimeraX silhouettes. Click Capture Current Scene after coloring to refresh the Illustrate snapshot.

The default contour level is 4, matching the reference Illustrate input; levels 1–3 remain available for sharper outlines. The default shadow floor and residue-number difference also follow that reference style. Output-size controls are arranged in one row, while style parameters are grouped into three columns for contours, boundaries, and atoms/shadows/fog. Reset Defaults restores preview size, export size, style values, shadow, transparency, and contour level without clearing the captured scene. The interface starts in English; use the 中文 button to switch between English and Chinese.

The default preview edge is 512 pixels, selected as a balance between readable detail and interactive updates, and the preview display remains height-bounded so opening the tool does not force the ChimeraX window off-screen. The Parameter Help button and control tooltips describe each parameter, practical ranges, and how larger or smaller values affect the image. Export width and height accept 2–8000 pixels. The original Fortran program used a fixed 3000-pixel frame buffer; this bundle uses dynamic NumPy buffers and scales the pixel-based contour, boundary, and shadow neighborhoods from a 1200-pixel reference so changing the export size does not substantially change the visual style. Exports above 4096 pixels are processed in row tiles to avoid constructing several full-frame temporary arrays at once; larger images still require more time and memory. Raster and shadow results are cached, transparent regions are excluded from post-processing, sphere rasterization is vectorized, and large soft-shadow passes use multiple CPU cores. PNG compositing, compression, and writing are streamed in the background so the ChimeraX interface remains responsive and high-resolution exports avoid a second full-frame RGBA allocation.

The output uses atomic spheres even when the source representation is cartoon or molecular surface; the original cartoon or surface mesh is not rasterized. The output uses an orthographic projection to match the original Illustrate renderer; perspective cameras are accepted but may show a scale difference.
